# 🔍 GitScout - Explore GitHub Profiles

GitScout ek modern Android application hai jo GitHub users ko search karne aur unki repositories ko scout karne ke liye banayi gayi hai. Is app ko kafi clean aur user-friendly banaya gaya hai.

---

## ✨ Features
* **User Search:** Kisi bhi GitHub username ko search karein.
* **Profile Details:** User ka Bio, Followers, aur Location dekhein.
* **Recent Projects:** User ki top 10 repositories ki list load karein.
* **Search History:** Purani searches save rehti hain taake aap bar-bar search na karein.
* **Direct Visit:** Ek click par GitHub profile browser mein kholain.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **Network:** Retrofit (for API calls)
* **Image Loading:** Glide
* **UI Components:** Material Design 3, RecyclerView, ShapeableImageView
* **Data Persistence:** SharedPreferences (for History)
